## Project overview

English Voice Coach AI helps English learners practice speaking through a terminal-based workflow:

```text
speak through the microphone
↓
manual recording controlled with Enter
↓
audio transcription
↓
AI correction and feedback
↓
text response from the coach
↓
follow-up question to continue the conversation
↓
conversation history saved in SQLite
```

The MVP focuses on **spoken input and text-based coaching**. Text-to-speech is intentionally not part of the required MVP, keeping the project simpler, cheaper to run and easier to maintain.
